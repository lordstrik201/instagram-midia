# instagram-midia

Repositório **público** só com as imagens usadas pelo
[instagram-automacao](https://github.com/lordstrik201/instagram-automacao).

A API do Instagram baixa cada imagem por um endereço público, e o repositório
principal é privado. Por isso as imagens ficam aqui e são servidas por
`https://raw.githubusercontent.com/lordstrik201/instagram-midia/main/<arquivo>`.

Não coloque nada além de imagens aqui: tudo neste repositório é visível para qualquer pessoa.
